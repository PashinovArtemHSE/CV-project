# 🎬 ChromaKey Video Processor

Вам предоставлено видео, в котором объекты сняты на однотонном фоне (например, зелёный или синий экран).  
Эта программа позволяет удалить выбранный фон и заменить его на цвет или изображение по выбору пользователя.  

---

## ✨ Функционал

- 📂 **Загрузка видео** — поддерживаются форматы: `.mp4`, `.mov`, `.avi`, `.mkv`, `.webm`
- 🎨 **Выбор цвета хромакея**:
  - через HEX-код
  - с помощью инструмента «пипетка» (по кадру видео)
- 🖼 **Замена фона**:
  - на однотонный цвет
  - на пользовательское изображение
- ⚙️ **Тонкая настройка параметров**:
  - `tolerance` — чувствительность к оттенкам (чем больше, тем больше оттенков удаляется)
  - `blur` — сглаживание краёв маски
  - `edge_thin` — сужение или расширение границ маски
  - `despill_strength` — удаление цветного ореола от фона
  - `alpha` — прозрачность объекта
- 👀 **Предпросмотр результата** — можно проверить до скачивания
- 💾 **Скачивание итогового файла** на устройство в формате `.mp4`

---

## 🛠 Используемые технологии

- [Python 3.11](https://www.python.org/)  
- [Flask](https://flask.palletsprojects.com/) — веб-фреймворк для интерфейса  
- [OpenCV](https://opencv.org/) — обработка видео и удаление фона  
- [NumPy](https://numpy.org/) — численные вычисления  
- [Pillow](https://pillow.readthedocs.io/) — работа с изображениями

2. Клонируйте репозиторий:
