# 🎬 Removing chromakey project

Эта программа позволяет удалить выбранный фон и заменить его на цвет или изображение по выбору пользователя.  

---

## ✨ Функционал

- 📂 **Загрузка видео** — поддерживаются форматы: `.mp4`, `.mov`, `.avi`, `.mkv`, `.webm`
- 🎨 **Выбор цвета хромакея**:
  - через HEX-код
  - с помощью инструмента «пипетка» (кликом на нужный фон в первом кадре видео)
- 🖼 **Замена фона**:
  - на однотонный цвет
  - на пользовательское изображение
- ⚙️ **Тонкая настройка параметров кеинга**:
  - `tolerance` — чувствительность к оттенкам (чем больше, тем больше оттенков удаляется) (0-255. Оптимально 30-120. По умолчанию 60)
  - `blur` — сглаживание краёв маски (0-15. 5-15 для плавных краёв)
  - `edge_thin` — сужение или расширение границ маски (Отрицательные значения — раздувают границу, положительные — сужают. -20 - 20)
  - `despill_strength` — удаление цветного ореола от фона (например, зелёного свечения по краям) (0.0 - 1.0. По умолчанию 0.3)
  - `alpha` — прозрачность объекта (0.0 - 1.0. От полностью прозрачного до полностью непрозрачного. По умолчанию 0.3)
- 👀 **Предпросмотр результата** — можно проверить до скачивания
- 💾 **Скачивание итогового файла** на устройство в формате `.webm`

## 🛠 Используемые технологии
- [Python 3.11](https://www.python.org/)  
- [Flask](https://flask.palletsprojects.com/) — веб-фреймворк для интерфейса  
- [OpenCV](https://opencv.org/) — обработка видео и удаление фона  
- [NumPy](https://numpy.org/) — численные вычисления  
- [Pillow](https://pillow.readthedocs.io/) — работа с изображениями

## 📂 Структура проекта
```
├── app.py               # Основное Flask-приложение
├── chroma.py            # Логика хромакея (удаление и замена фона)
├── templates/           # HTML-шаблоны
│   ├── index.html       # Главная страница (загрузка видео)
│   ├── pick_color.html  # Выбор цвета/фона
│   ├── preview.html     # Предпросмотр результата
├── static/              # Загружаемые файлы и результаты
│   ├── uploads/         # Исходные видео и изображения (добавляется впоследствии программой)
│   └── outputs/         # Обработанные видео (добавляется впоследствии программой)
├── requirements.txt     # Зависимости Python
├── Dockerfile           # Docker-образ приложения
├── docker-compose.yml   # Конфигурация docker-compose
├── videos/              # Примеры видео, в которых можно вырезать фон
├── background/          # Примеры фото, которые можно поставить вместо вырезанного фона
└── README.md            # Документация проекта
```

## 🚀 Установка и запуск

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/PashinovArtemHSE/CV-project.git
   ```
2. Перейдите в папку с проектом
   ```
   cd CV-project
   ```
4. Запустите Docker
   ```
   docker-compose up --build
   ```
5. Откройте страницу на локальном сервере
   ```
   http://127.0.0.1:5000/
   ```
